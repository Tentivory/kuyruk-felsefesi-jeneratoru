# 🧘 Kuyruk Felsefesi Jeneratörü

## Dünyanın En Ciddi, En Bilimsel ve En Gereksiz Projesi

Bu repository, insanlığın en büyük varoluşsal sorununa çözüm üretir: **Kuyrukta beklemek**.

### Neden Var?

Çünkü kuyrukta beklerken telefonuna bakmak artık yetmiyor. Derin düşünmek lazım. Bu yazılım, kuyrukta geçirdiğin her saniyeyi felsefi bir şölene dönüştürür.

### Özellikler

- Tamamen çalışan Python kodu
- Rastgele derin (veya derin görünen) felsefi sözler
- Dramatik bekleme efektleri
- Bilimsel olarak hiçbir şey kanıtlamaz ama iddia eder
- Kuyrukları ortadan kaldırmaz, onlara anlam katar

### Kurulum ve Kullanım

```bash
python kuyruk_felsefesi.py
```

Evet, bu kadar. Daha karmaşık bir şey bekleme. Kuyrukta zaten yeterince karmaşıksın.

### Bilimsel Kanıt

Araştırmalar (ki yok) gösteriyor ki kuyrukta felsefe yapan insanlar %47 daha az öfkeleniyor. Kaynak: Benim hayal gücüm.

### Katkıda Bulunma
